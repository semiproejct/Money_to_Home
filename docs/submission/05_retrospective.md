# 5. 팀 회고

- 프로젝트: 머니 to 홈 (광주 5개 구 아파트 내 집 마련 시뮬레이터)
- 기간: 2026-10-06 ~ 10-21 · 팀: 김해원(팀장) · 김목산 · 박채은 · 안세환
- 문제별 원인과 해결은 [트러블슈팅 보고서](03_troubleshooting.md)에 있습니다.

## 잘된 점

- 팀장의 정리와 가이드(처음 Git 사용법, 매일 아침 최신화 순서) 덕분에 계획적으로 진행했습니다.
- 팀원마다 피드백 · 질문방을 두어 의견과 수용이 빨랐고, 분쟁 없이 마무리했습니다.
- 문서 정리가 잘 되어 있었고, 특히 CLAUDE.md(AI에게 주는 공통 규칙)가 네 명의 결과물을 같은 모양으로 맞춰 준 핵심이었습니다.

## 어려웠던 점

- **데이터:** 옛 지역 코드, 건축물대장 수집, 기간 13 → 12개월, 세대수 보정에 시간이 걸렸습니다.
- **화면:** 조건 창처럼 미끄러져 나오는 요소가 지도를 미는 문제, 로드뷰처럼 사소한 이유로 안 나오는 디테일, 헤더처럼 사람이 정해야 하는 UI가 어려웠습니다.
- **협업:** 정리가 안 돼 작업이 지워져 다시 한 일도 있었습니다.

## 배운 점

- 처음의 문서 작성과 가이드라인이 얼마나 중요한지 배웠습니다.
- Git 브랜치 · PR · 충돌 풀기를 익혔습니다.
- 서로 피드백하며 소통하니 협업하는 느낌이 들었고, 문제를 하나씩 풀며 많이 늘었습니다.
- 코드는 AI가 빠르게 쓰지만, 사용자에게 보이는 UI는 사람이 정하고 세세하게 잡아 줘야 합니다.
