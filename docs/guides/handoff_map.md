# 세환님께: 지도 화면에서 바뀐 것 (2026-10-13)

팀장이 지도 화면의 두 가지(진짜 자료 연결, 구·동 선택)를 만들면서 세환님의 파일을 고쳤습니다.
아래 창을 이어서 만들기 전에 이 글을 읽고 `develop`을 받아 주세요.

| 항목 | 내용 |
| --- | --- |
| 브랜치 | `feature/map-real-data` |
| 고친 세환님 파일 | `frontend/js/map-view.js`, `frontend/css/map.css`, `frontend/map.html` |
| 새 파일 (팀장) | `frontend/js/region.js`, `frontend/css/region.css` |
| 보는 곳 | `http://localhost:8000/map.html` (입력을 넣은 뒤) |

## 1. 먼저 할 일

PR이 머지되면 작업 브랜치에서 바로 실행합니다. 늦을수록 충돌이 커집니다.

```
git fetch origin
git merge origin/develop
```

- `CONFLICT`가 나오면 멈추고 팀장에게 알려 주세요. `map-view.js`를 같이 고쳤다면 날 수 있습니다.
- 합친 뒤에는 Claude 대화를 새로 엽니다. `CLAUDE.md`가 바뀌었습니다.
- 브라우저는 Ctrl+F5로 새로 고칩니다. `map.html`의 `?v=` 숫자를 올려 두었습니다 (`map.css?v=20261013-6`, `map-view.js?v=20261013-9`).

## 2. 무엇이 바뀌었나

### 2.1 예시 자료가 없어졌다

- `PREVIEW`, `PREVIEW_INPUT`, `PREVIEW_REGION`, `PREVIEW_SEARCH`, `fitToMarkers`를 지웠습니다.
- 화면 맨 처음에 `guard.requireInput()`을 부릅니다. 입력이 빠졌으면 그 단계로, 값이 하나도 없으면 시작 화면으로 갑니다.
- 그래서 **지도를 보려면 입력을 먼저 넣어야 합니다.** 시작 화면부터 끝까지 넣거나, 개발자 도구의 콘솔에 아래를 넣고 새로 고칩니다.

```js
sessionStorage.setItem('mth.input', JSON.stringify({
  age: 29, annual_income: 36000000, current_assets: 50000000,
  loan_choice: 'product', loan_product_id: 1, repayment_years: 30,
  monthly_saving: 1000000, target_years: 5,
}));
```

### 2.2 `mapState`에 생긴 값

| 값 | 내용 |
| --- | --- |
| `mapState.data` | A-05(`POST /api/apartments/search`)의 응답. 예전의 예시 자료와 모양이 같다. |
| `mapState.regions` | A-02(`GET /api/regions`)의 `regions` |
| `mapState.region` | 보고 있는 지역 `{ gu, dong }`. `dong`이 `null`이면 구 전체 |
| `mapState.wide` | 지금 동 표시를 그리고 있는가 (넓게 보는 중) |

보고 있는 지역은 `store.set('map', { gu, dong })`으로 보관합니다. 새로 고쳐도 그 지역으로 돌아옵니다.

### 2.3 새로 생긴 함수

| 함수 | 하는 일 |
| --- | --- |
| `loadData()` | 지금 지역의 아파트를 받아 `mapState.data`에 넣고 `renderCondition()`, `renderMarkers()`를 부른다. 실패하면 앞의 자료를 두고 알림을 띄운다. |
| `moveToRegion({ gu, dong })` | 지역을 바꾸고, 지도를 옮기고, `loadData()`를 부른다. 구·동 선택 창이 부른다. |
| `zoomToDong({ gu, dong })` | 동 표시를 눌렀을 때. 그 동이 가운데로 오면서 0.6초 동안 확대된다. |
| `renderRegionName()` | 지역 버튼의 글자. "서구 치평동", 구 전체면 "서구 전체" |
| `regionCenter({ gu, dong })` | 그 지역의 위치 (A-02의 값) |
| `onZoomChanged()` | 확대 수준이 바뀌어 말풍선과 동 표시가 서로 바뀔 때 다시 그린다. |

### 2.4 넓게 보면 동 표시 (P-05 ③)

- 확대 수준이 **6 이상**이면 말풍선 대신 동마다 표시 하나를 그립니다 (`DONG_MARKER_LEVEL`).
  동 하나를 볼 때는 5(`DONG_LEVEL`), 구 전체는 7(`GU_LEVEL`)입니다. 와이어프레임에 "미정"이던 값을 이렇게 정했습니다.
- 동 표시는 연보라 동그라미에 동 이름과 숫자입니다 (`.dong-marker`, 색은 `--color-dong`).
  숫자는 그 동에서 목표할 수 있는 아파트 수(지금 가능 + 기간 내 가능)입니다. 0이면 점선 테두리입니다.
- 동 하나를 보다가 축소하면 그 구 전체를 받아 동 표시를 그리고, 지역 버튼이 "○○구 전체"로 바뀝니다.
- 동 표시를 누르면 그 동으로 확대되고 말풍선으로 돌아갑니다.

### 2.4-1 더 넓게 보면 구 표시, 가까이 보면 겹친 말풍선 묶기 (2026-10-13 저녁에 더함)

- 확대 수준이 **8 이상**이면 동 표시 대신 구마다 표시 하나를 그립니다 (`GU_MARKER_LEVEL`). "광산구 / 216" 모양이고 숫자의 뜻은 동 표시와 같습니다.
  지역 버튼은 "광주 5개 구 전체"가 됩니다. 동 표시와 구 표시의 수와 자리는 구별·동별 개수 API(A-12)에서 받습니다 (2026-10-14에 바꿈). 동은 5개 구의 모든 동을 한 번에, 구는 5개를 한 번에 받고, 한 번 받으면 다시 받지 않습니다 (`mapState.summary`).
- 구 표시를 누르면 그 구가 가운데로 오면서 확대되고 동 표시가 나옵니다. 손으로 확대하면 지도 가운데에서 가장 가까운 구를 보여 줍니다.
- `mapState.wide`는 없어지고 **`mapState.mode`**(`'apartment'`, `'dong'`, `'gu'`)가 생겼습니다. `zoomToDong`은 `zoomToRegion({ gu, dong })`으로 바뀌었습니다.
- 가까이 볼 때 말풍선끼리 넓이의 35% 넘게 겹치면 하나로 묶습니다 (`groupOverlapping`). 앞의 하나만 그리고 가려진 수를 "+2"로 적습니다 (`.marker__more`).
  묶인 말풍선을 누르면 한 단계 확대해 풉니다 (`openGroup`). 좌표가 똑같아 풀 수 없는 아파트는 누를 때마다 다음 아파트가 앞으로 나옵니다.
- **말풍선을 눌렀을 때 30% 창을 붙일 자리가 두 군데가 됐습니다.** 하나짜리 말풍선은 `selectMarker(id)`, 묶인 말풍선은 `openGroup(group)`입니다. 묶인 말풍선은 풀린 뒤에 다시 눌러야 하나가 골라집니다.
- 자금 부족 표시를 끄면 자금이 부족한 아파트는 아예 그리지 않습니다 (예전에는 CSS로 숨겼습니다). 묶음을 셀 때도 빠집니다.

### 2.5 자금 부족 표시는 처음에 꺼져 있다

- 스위치의 처음 상태를 "켜짐"에서 **"꺼짐"**으로 바꿨습니다 (2026-10-13에 정함). 자금이 부족한 아파트의 말풍선은 스위치를 켜야 보입니다.
- 켜고 끈 상태는 예전처럼 `store`의 `map.show_lack`에 둡니다. 값이 `true`일 때만 켜진 것입니다.

### 2.6 구·동 선택 창 (P-05 ⑬)

- `js/region.js`와 `css/region.css`에 따로 있습니다. `map.html`에는 자리 하나만 넣었습니다.

```html
<section class="region-sheet" id="region-sheet" aria-label="지역 선택" hidden></section>
```

- 쓰는 방법: `regionPicker.open(요소, mapState.regions, mapState.region, moveToRegion)`
- 구의 순서는 목업대로 동구, 서구, 남구, 북구, 광산구입니다.
- 창은 `.map-app`의 아래쪽에 붙고 높이는 72%, `z-index`는 5입니다.

## 3. 아래 창을 만들 때 맞출 것

| 맞출 것 | 내용 |
| --- | --- |
| 목록을 다시 그리는 때 | 지역이 바뀌면 `loadData()`가 끝난 뒤입니다. `loadData()`의 끝에서 목록도 다시 그리게 한 줄을 넣으면 됩니다. |
| 목록 | `listView.render(요소, mapState.data, { where: mapState.region, onSelect, onClose })`. 요소는 `<div id="apt-list"></div>` (김목산의 `js/list.js`) |
| 창이 겹칠 때 | 구·동 선택 창이 5입니다. 아래 창이 열려 있을 때 지역 버튼을 누르면 어느 쪽이 위에 올지 정해 주세요. |
| 동 표시를 눌렀을 때 | 와이어프레임은 그 동으로 확대하고 30% 창이 올라옵니다 (P-06 ④). 지금은 확대만 합니다. `zoomToDong()`의 끝에 붙이면 됩니다. |
| 말풍선을 눌렀을 때 | `selectMarker(id)`는 그대로입니다. 30% 창(P-06 ⑥)을 여기에 붙이면 됩니다. |

## 4. 남아 있는 것

| 남은 것 | 내용 |
| --- | --- |
| 말풍선이 조금 겹친다 | 많이 겹치는 것은 묶었지만(2.4-1), 35% 아래로 겹치는 말풍선은 그대로 서로 조금씩 가립니다. |
| 현재 위치 버튼 | 지도만 옮깁니다. 다른 동으로 가도 아파트를 다시 받지 않습니다. 그대로 두기로 했습니다. |
| 처음 지역 | 서구 치평동입니다 (`DEFAULT_REGION`). 문서에는 "정할 것"으로 남아 있습니다. |
| 지도 영역으로 찾기 | 김목산이 `bounds`를 만든 뒤에, 지도를 움직일 때마다 받는 방식으로 바꿉니다. 그때까지는 구·동을 고를 때만 받습니다. |
| 확대·축소 버튼 | 축척 글자가 바뀌는지 팀장 쪽에서 확인하지 못했습니다. 한 번 눌러 봐 주세요. |
